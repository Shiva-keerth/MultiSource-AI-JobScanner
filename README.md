# MultiSource AI Job Scanner

An intelligent, multi-platform job aggregation and evaluation pipeline designed to autonomously fetch, filter, and score software engineering and AI roles.

## Features
- Integrates with multiple job boards (Adzuna, HackerNews, RemoteOK)
- Uses Groq's Llama-3 model for semantic parsing and candidate-fit evaluation
- Strict filtering to drop generic IT service company "fake fresher" roles
- Automated email reports with HTML styling using SMTP
